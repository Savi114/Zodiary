# Zodiary

A Java console application for exploring astronomical observations, developed as part of my Java coursework at Touro University Berlin.

## About the project

Zodiary helps me put what I learn in class into practice through a working application. It uses supplied astronomical data and console input to explore observations.

## Features

- Loads observation data from CSV files.
- Accepts user selections through the console.
- Checks input and asks again when an entry is invalid.
- Displays observation results for the selected location and planet.

## Skills and tools

- Java
- Object-oriented programming
- Classes, inheritance, and polymorphism
- CSV file handling
- Input validation
- IntelliJ IDEA

## Project folders

- `src/` — Java source code.
- `Data/` — Data files used by the application.

## Running the project

1. Download the repository using **Code → Download ZIP**.
2. Extract the ZIP and open the project folder in IntelliJ IDEA.
3. Configure a Java Development Kit (JDK).
4. Set `src` as the Sources Root if IntelliJ does not recognise it automatically.
5. Keep the working directory set to the project folder so the application can find `Data`.
6. Open `Main.java` and run its main method.
7. Follow the instructions in the console.
